#extincions_orionPMS
#This repository have the table of the extinctions values derived with the MHEEF (C.E. Zepeda in prep) and MassAge (J. Hernandez in prep) tool.

## Table: extinciones_todas_AvH+AvMA.csv
### Columns

| Column      | Description                                          | Units    |
|-------------|------------------------------------------------------|----------|
| APOGEE_ID   | Identificador único de la estrella en APOGEE         | —        |
| RA          | Ascensión recta                                      | deg      |
| DEC         | Declinación                                          | deg      |
| Av          | Extinción visual MHEEF                               | mag      |
| varAv       | Varianza de la extinción visual MHEEF                | mag      |
| Av_med      | Mediana de la extinción visual MassAge               | mag      |
| e_Avmed     | Error de la mediana de la extinción visual  MassAge  | mag      |
